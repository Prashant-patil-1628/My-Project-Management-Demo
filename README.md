# My-Project-Management-Demo
## LinkedIn skills

This repo includes 12 Claude Code skills for LinkedIn (post writing, comments,
replies, humanizing drafts, content planning, profile optimization and more),
vendored from [sergebulaev/linkedin-skills](https://github.com/sergebulaev/linkedin-skills)
under the MIT license. Open the repo in Claude Code and ask for help with
LinkedIn; the matching skill loads automatically. See `CLAUDE.md` for setup.
